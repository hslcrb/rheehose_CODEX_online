# NTC (New Technology Compiler)

NTC는 GCC를 100% 대체하는 것을 목표로 하는 프로젝트입니다. 현재 코어 드라이버는 **100% C 언어(C11)** 로 작성되어 있습니다.

## 이번 구현 핵심

- 단일 바이너리 `ntc` (`src/ntc.c`)
- 호스트 `clang/gcc` 자동 탐지
- 두 가지 실행 전략
  - **NTC 가속 파이프라인**: C 계열 소스 컴파일 시 병렬 컴파일 + 캐시
  - **호환 패스스루**: 복잡/비표준 인자는 그대로 호스트 컴파일러에 위임
- 병렬 빌드: `-j N`
- 캐시: `.ntc-cache` (소스+플래그+컴파일러 키)

## 왜 패스스루가 중요한가

GCC 100% 호환은 방대한 옵션/타겟/ABI/툴체인 생태계 전체를 포함합니다.
따라서 현재 단계에서는 **호환성 보존(패스스루)** + **성능 경로(병렬/캐시)** 를 동시에 제공해, 실제 워크로드에서 즉시 쓸 수 있는 형태로 구성했습니다.

## Build

```bash
make
```

## Test

```bash
make test
```

## Usage

```bash
./ntc hello.c -O2 -o hello
./ntc -c hello.c -O3 -o hello.o
./ntc a.c b.c -j 8 -O2 -o app
```
